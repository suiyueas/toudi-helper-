<h1 align="center">toudi-helper-</h1>

基于 Tampermonkey（篡改猴）的全平台自动求职投递脚本。支持 **BOSS 直聘**、**智联招聘**，内置智能关键词评分（过滤全栈/销售等坑岗）、自动打招呼、自定义文本及数据导出，帮你高效海投。

> ⚠️ 本脚本仅供个人求职效率工具使用，请遵守目标招聘平台的服务条款，控制投递频率，风险自负。

## 功能特性

- **多平台支持**：BOSS 直聘、智联招聘，数据完全隔离，互不干扰。
- **智能评分筛选**：
  - 正面/负面关键词打分，岗位名与技能命中额外加权；
  - 长词优先去重（`Java` 与 `Java后端` 对同一段文字只计一次，不再叠分）；
  - 岗位名直接含负面词硬否决（不看分数直接跳过）；
  - 核心词必中、否定上下文识别（如"不招运维"不计分）；
  - 可选 OpenAI 兼容接口做语义评分（-10 ~ +20）。
- **多维过滤**：城市、薪资区间、公司筛选/黑名单、公司已投递去重（跨批次）。
- **跨批次去重**：跳过历史已沟通岗位（读取本地 IndexedDB 索引，刷新后依然生效）。
- **自动投递主流程**：列表选岗 → 点击沟通 → 聊天页发送问候语/自定义文本 → 返回列表继续，随机时间间隔防检测。
- **弹窗处理**：沟通次数提醒自动确认，硬限制自动暂停。
- **数据管理**：岗位沟通记录导出（JSON/CSV）、一键清理、运行统计与 7 日趋势。
- **右侧控制面板**：全部参数可视化配置，实时日志、评分结果与状态提示。

## 安装

1. 安装浏览器扩展 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 点击下方按钮安装脚本（或将 [`jobfind-assistant.user.js`](./jobfind-assistant.user.js) 内容复制到 Tampermonkey 的"添加新脚本"中保存）：

   [![Install](https://img.shields.io/badge/安装-用户脚本-brightgreen)](./jobfind-assistant.user.js)

3. 打开 [BOSS 直聘](https://www.zhipin.com/) 或 [智联招聘](https://www.zhaopin.com/) 的岗位列表页，右上角会出现脚本控制面板。

## 快速上手

1. 打开面板 → **评分筛选**，填写正面关键词（如 `Java,Spring,后端`）与负面关键词（如 `销售,直播,客服`）。
2. 按需勾选城市、薪资、黑名单等过滤条件。
3. 在 **运行策略** 中设置随机间隔、最大沟通数，按需勾选「跳过历史已沟通岗位」。
4. 点击 **开始**，脚本会自动筛选、沟通并记录；面板可随时暂停/停止。
5. 运行结束后在 **数据** 页导出沟通记录。

### 推荐评分参数

| 参数 | 建议值 | 说明 |
|---|---|---|
| 正面权重 | 8 | 每命中一个正面词加分 |
| 负面权重 | 60~80 | 去重后每个负面词只扣一次 |
| 岗位名加权 | 12 | 正面词出现在岗位名时额外加分 |
| 技能加权 | 6 | 正面词出现在技能标签时额外加分 |
| 负面·岗位名扣分 | 40 | 负面词出现在岗位名时额外扣分 |
| 高分阈值 | 70~80 | 达到即 good，直接投递 |
| 中分阈值 | 30~40 | 达到即 mid，直接投递 |
| 核心词必中 | `java,spring` | 岗位需命中其一才投，留空不启用 |

> 面板配置保存在浏览器 localStorage，改代码里的默认值对已保存的配置无效，请直接在面板中修改。

## 数据存储

| 存储 | 位置 | 用途 |
|---|---|---|
| 岗位沟通记录 | IndexedDB（按域名隔离） | 历史记录、导出、已沟通索引 |
| 运行状态 | localStorage | 页面跳转/刷新后恢复自动化状态 |
| 面板配置 | localStorage | 全部可调参数 |
| 已投递公司名单 | localStorage | 跨批次公司级去重 |

清空浏览器数据会同时清空以上记录，重要数据请先在"数据"页导出。

脚本内部主要模块（单文件内按注释分区）：

- `RunState` — 跨页面状态机持久化
- `JobRepository` — 岗位数据归一化与匹配
- `Database` / `ContactedIndex` — IndexedDB 存储与已沟通索引
- `ScoreService` — 关键词评分与等级判定
- `FastReplyService` / `GreetingService` — 常用语与自定义文本发送
- `Automation` — 投递主流程（列表 → 聊天 → 返回）
- `Exporter` / `RecordCleaner` — 记录导出与清理

## 常见问题

- **脚本不显示面板**：确认已启用脚本，且当前页面 URL 与 `@match` 规则匹配。
- **改了代码不生效**：需在 Tampermonkey 中重新保存脚本并刷新页面。
- **提示未登录**：先在目标站点登录账号再启动。
- **频繁跳过岗位**：检查评分阈值是否过高、核心词是否过窄，参考上文推荐参数。
